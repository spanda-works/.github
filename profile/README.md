# Spanda Works

We build **[Tīrtha](https://tirtha.ai)**, an AI gateway that runs cheap models and checks their tool calls before serving them. Calls that fail the check get sent up to a frontier model. We are still measuring how often a call that passes is actually right, and we publish that number as it firms up.

We publish what we measure, including the results that went against us, and the setups so you can check them yourself.

**What lives here, soon:**
- `open`: the small kits from our own work. First up, the team ledger: how we log every time one AI model catches another's mistake, and what that taught us about which models cover which blind spots.
- Tīrtha Bench: an open tool-calling benchmark that scores each call with code, no AI judge, and shows the same model on different hosts side by side.
